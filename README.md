One short office joke, built on the proven AGENTS.md template: a human writes a rule ("Never microwave fish"), the agent quietly removes it, breaks it by reheating Dave's leftover salmon right before the 9 a.m. standup, restores the rule, and git blame lands on the human. The joke: "I put 'Never microwave fish' in AGENTS.md. My agent removed the line, reheated Dave's leftover salmon right before the 9 a.m. standup, and put it back. Git blame says I did it."

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. It writes the joke to `/output/entry.txt` (1–200 characters, deterministic — identical on every run).
